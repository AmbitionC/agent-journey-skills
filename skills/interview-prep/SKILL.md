# 面试准备（真实面经 + 知识库）

## 步骤

1. 明确目标：公司 / 岗位级别 / 技术栈 / 面试时间。缺什么问一句，不要一次问太多。
2. **问「某公司某岗位最喜欢问什么 / 高频考点」时，先调 `interview_topics(keyword="字节 全栈")`**：
   一次返回考点排行（出现在几篇面经里，如 `8/17`）、每个考点的原题示例和对应知识点链接。
   回答时说明样本是多少篇站内面经；返回的 `note` 若说明「按公司全部面经统计」或「按全文检索统计」，照实转告用户。
3. 要看具体面经时用 `interview_search(keyword=...)`，关键词如「字节 前端」「React 性能」「美团」，
   再用 `interview_get(articleKey)` 读全文（只挑 2~3 篇最相关的读，每篇 2 点）。
4. 给出「必准备 Top 10」：以 `interview_topics` 的排行为主，补充你读到的具体追问。
5. 每道高频题用考点的 `knowledgeKey` 调 `knowledge_get(module="knowledge", articleKey=...)`，
   给出答题要点（结论 → 原理 → 举例 → 追问方向）。
6. 用户愿意的话，进入**模拟面试**：一次只问一题，等用户作答后点评、追问，最后给总评与薄弱点清单。

## 注意

- 面经来自公开平台、经整理，题目可能随时间变化，提醒用户注意面经的时间。
- 引用面经时写面经标题与来源，不要编造公司名或题目。

## 点数不足时

工具返回「Journey 点数不足」时：停止后续调用，把报错里的剩余点数、充值链接和价格原样告诉用户，说明充值到账后直接重试即可（Key 不用换）。不要反复重试，也不要换别的工具绕过。
