# 面试准备（真实面经 + 知识库）

## 步骤

1. 明确目标：公司 / 岗位级别 / 技术栈 / 面试时间。缺什么问一句，不要一次问太多。
2. `interview_search(keyword=...)` 检索面经，关键词如「字节 前端」「React 性能」「实习 一面」。
   - 默认看前 10~20 条；需要更多翻页（`page`）。
3. 对相关度高的 3~5 篇用 `interview_get(id)` 读全文。
4. **归纳**：把题目按主题聚类（JS 基础 / 框架 / 网络 / 工程化 / 算法 / 项目深挖 / AI 应用），
   标出出现频次，给出「必准备 Top 10」。
5. 每道高频题用 `knowledge_search` 找对应知识点，给出答题要点（结论 → 原理 → 举例 → 追问方向）。
6. 用户愿意的话，进入**模拟面试**：一次只问一题，等用户作答后点评、追问，最后给总评与薄弱点清单。

## 注意

- 面经来自公开平台、经整理，题目可能随时间变化，提醒用户关注时间（`publishTime`）。
- 引用面经时写面经标题与来源，不要编造公司名或题目。
