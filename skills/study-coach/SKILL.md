# 学习规划与自测

## 规划

1. 问清目标（求职 / 补短板 / 系统学习）与每周可投入时间。
2. `knowledge_tree(module="knowledge")` 取目录，按依赖顺序排出 2~6 周计划，每周 3~5 篇。
3. 计划写成清单交给用户；用户在本地有项目目录时，可以存成 `study-plan.md` 便于勾选。

## 自测

1. 用户读完某篇后，`quiz_get(module, articleKey)` 取配套自测题（只含题干和选项）。
2. 一次出一题，等用户作答后再讲解；讲解依据用 `knowledge_get` 读原文。
3. 没有配套题时，根据原文自行出 3 道题，并说明是你出的题。
4. 结束时给出掌握度评估与建议复习的文章。

> 学习进度目前保存在用户自己那边（对话或本地文件）；服务端进度托管会在后续版本提供。
